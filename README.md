# Full Stack Development: Guessing Game Tutorial

Guessing game is a complete step by step tutorial on how to build a simple full stack web app.

## How It Works

There is a Jupyter Notebook called project.ipynb that contains both a small blog about how
I landed at making this tutorial and the actual steps to building this application. Just follow
the tutorial and you can learn how to build the different layers that make up the backend and frontend.

## Repo Layout

```text
-> guessing-game/
    -> .venv/
    -> backend/
        -> main.py
        -> requirements.txt
    -> frontend/
        -> script.js
        -> style.css
        -> index.html
    -> .gitignore/
```

## Concluding Thoughts

I built this tutorial for fun. I realized that this was a core critical knowledge gap when I
was editing other repos I've worked on since I had an already established codebase and I finally
got to the accounting aspect of why it looks the way it looks and works the way it works. I am
convicted that to be successful long-term with agentic coding I need to understand what it is
I am building or else when projects get left in the dust and some maintenance needs to happen,
I won't know the first place to start and will just be full dependent on the AI to make all decisions
for me. This is what drove to to dive deeper, learn more, and better prepare myself for ongoing and future
projects.
